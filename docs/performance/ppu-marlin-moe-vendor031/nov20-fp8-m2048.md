# PPU FP8 W8A16 at M=2048

The lowest-speedup shape from the prior checkpoint is M2048, 256 experts, hidden size 4096, intermediate size 256, and top-k 6. Both projections now use a 64-route by 128-column tile. Eight warps share each decoded weight fragment across four 16-route BF16 MMA instructions. Per K128 step, the PPU AIU copies one FP8 weight tile and two BF16 activation planes. TLE gpu.alloc and gpu.local_ptr provide the 64 KiB shared double buffer. Inline ppu.cp.async and ppu.ldmatrix stage and load fragments for ppu.mma.sync.aligned.m16n16k16. The existing live scale checks select exact folded or robust FP8 decoding.

The tile is selected for contiguous FP8 weights and BF16 activations and scales with group size 128, hidden size 4096, intermediate size 256, top-k 4–8, 1024–4095 tokens, and a route count above 32 and at most 64 per expert on average. It requires at least 64 KiB opt-in shared memory per CTA. Padded routes, FP32 accumulation and the BF16 projection boundaries follow the existing grouped path.

## Performance

The reference is SAIL 0.33.0rc1 and vLLM 0.33.1.dev0 native BF16 MoE on PPU-ZW810E. It consumes the same decoded weights using FusedMoEKernel.apply in BF16 mode. The input generation, shape provenance, timing protocol and error thresholds follow the previous checkpoint. [Native API and protocol](nov20-fp8-routing.md) · [53-shape latency and accuracy table](nov20-fp8-m2048.csv).

All 53 DeepSeek-V4-Flash shapes passed in the optimized run. The minimum is 0.859480× at M=2048 and the maximum is 2.194106× at M=2. The count-weighted speedup is 1.302610× across 10,105 calls. The M=2048 shape accounts for 43 calls.

On a single card, the optimized M=2048 output matched the old implementation bit for bit. That A/B measured 2.288107 ms before and 1.616340 ms after. Isolated CUDA Graph replays measured approximately 0.679 ms for gate/up and 0.748 ms for down. The previous grouped fast kernels measured 1.292 ms and 0.759 ms respectively, with additional launches for the robust scale cases. The new kernels use 64 KiB shared memory and 76/74 registers per thread for gate/up and down, with zero spills.

## Validation

Twelve FP8 CUDA Graph tests passed. The added case exercises the wide tile, routed expert changes within a captured graph, large down-projection scales, and both router-weight positions. The nominal M=2048 input passed the same native and FP32 gates in both native runs. The candidate used SDK 2.2.0-663c22, vendor Torch 2.13.0, and FlagTree 0.7.0+ppu.git1a96a36a.
